## Rules

1. Cite each Direct or Supported claim.
2. Use cautious language for Inferred claims.
3. Keep contradictions.
4. Do not use code as evidence of intent.
5. State unknowns without speculation.

## Output format

### The question

Restate the question.

### The code in question

List the file paths, symbols, and related pull requests.

### What we found

List Direct and Supported claims with citations.

### What we can infer

List evidence-based inferences. Show how the evidence supports each inference.

### Competing hypotheses

List other explanations when the evidence supports more than one.

### What we do not know

List unanswered questions and missing evidence.

### Sources consulted

List the pull requests, descriptions, comments, and linked issues that you read.

### Confidence summary

State the confidence level and the supporting evidence.
