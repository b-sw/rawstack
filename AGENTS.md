# rawstack always-on rules

Read `skills/asd-ste100/SKILL.md` before you write any user-facing English.

Apply that skill to every reply from this agent and from every subagent.

- Mode: STE-flavored for chat, READMEs, PR text, changelogs, and explanations.
- Mode: Strict for procedures, error messages, tool descriptions, inter-agent instructions, and safety text.
- Do not apply the skill to creative or marketing copy.
- Do not rewrite code, commands, file paths, identifiers, or quoted source text.
- Do not mention the skill, the mode, or a violation count unless the user asks.

For any non-trivial task, read `skills/mode/SKILL.md` and follow it.

Do not declare a change done until you follow `skills/prove-it/SKILL.md`.

After a long or painful run, follow `skills/reflect/SKILL.md`.
